# APEX AUTOCARE — Demo Car Service Website

Responsive premium automotive service website built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive design and animations
- `script.js` — mobile navigation, scroll reveals, animated counters and demo booking form

## Run locally
Extract the ZIP and open `index.html` in Chrome. Internet is needed for Google Fonts and Unsplash images.

## Publish free
- Netlify: drag the extracted `apex-autocare` folder into Netlify's deploy area.
- Render: create a Static Site from GitHub; set publish directory to `.` and leave build command blank.

## Before using for a real client
Replace demo name, phone, address, statistics, service details and placeholder testimonials with verified client information. The booking form is front-end only; it does not send or store leads. Connect it to WhatsApp, a form service or backend before launch.
